# Calculadora

Calculadora Expo para Android, optimizada para uso en pantalla compacta. Incluye operaciones aritméticas, trigonometría en grados o radianes, vibración al calcular y gráfica cartesiana.

## Iniciar en Expo Go

Desde la raíz del workspace:

```bash
cd .Calculadora
npx expo start --tunnel ngrok
```

Escanea el QR del terminal con Expo Go en el teléfono. Mantén el servidor abierto mientras uses la app.
